# 2026-09-29 — дерево: переключатель Board / Tree на странице проекта (beads-web-0l7.3)

В строке фильтров (`src/components/quick-filter-bar.tsx`) слева от поиска
появились две кнопки-значка — `Board view` и `Tree view` (`aria-pressed`,
подсказка в `title`). Выбор хранится в адресе: `?view=tree`, без параметра —
доска, любое другое значение — тоже доска. Разбор и сборку адреса делают
`parseProjectView` и `projectViewSearch` (`src/lib/project-view.ts`), хук
`useProjectView` (`src/hooks/use-project-view.ts`) меняет адрес через
`router.replace`, сохраняя `id` и остальные параметры. Отрисовка колонок
вместе с `useKeyboardNavigation` вынесена из `src/app/project/kanban-board.tsx`
в `src/components/board-view.tsx`; поэтому клавиши доски в виде дерева не
работают сами собой — хук просто не смонтирован. Заодно из страницы вынесены
шапка (`src/components/project-header.tsx`) и предупреждение про GitHub
(`src/components/github-warning-dialog.tsx`); страница стала 464 строки вместо
544. Для дерева страница передаёт `matchedIds` (отфильтрованные задачи плюс
фильтр типа, без `selectBoardBeads` — у дерева дети эпиков свои строки) и
`compare` из сортировки строки фильтров, оба через `useMemo`; `openBead` из
`useBeadDetail` уже стабилен.

**Что проверить первым, если сломается.** Переключатель нажимается, а вид не
меняется — смотреть, что `useSearchParams` отдаёт новый `view` после
`router.replace` (статический экспорт Next.js). Дерево тормозит при каждом
вводе — пересоздаётся `treeMatchedIds` или `treeCompare` в `kanban-board.tsx`.
Ошибка в одном виде не мешает другому: граница ошибок в `<main>` получает
`key={view}` и сбрасывается при переключении.

**Оставлено как есть.** В виде дерева не работают клавиши доски: `j`/`k` и
стрелки вверх-вниз, `Enter`, `g` + `o`/`p`/`c`/`1`–`9`, `/` (фокус поиска) и
`Escape` для снятия выделения и выхода из поиска. `Escape` по-прежнему
закрывает карточку — это делает сама карточка. Клавиатура дерева — часть
beads-web-0l7.4.
