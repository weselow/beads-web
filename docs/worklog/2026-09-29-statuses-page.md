# 2026-09-29 — страница: статусы как данные вместо 4 зашитых (beads-web-5fk.2)

Страница больше не переписывает статус задачи при загрузке. Раньше
`mapBeadStatus` превращал blocked и deferred в open, hooked в in_progress, а
настоящий статус прятал в `_originalStatus`. Теперь `bead.status` — строка
ровно в том виде, как её держит bd (`blocked`, `pinned`, свой `inreview`).
При загрузке (`src/lib/beads-parser.ts`, `normalizeBeadStatus`) остались
только синонимы старых bd: done и resolved → closed, pending → open, а
tombstone (удалённая задача) скрывается. Список статусов проекта берётся из
`GET /api/statuses` (задача 5fk.1): `api.statuses.get` → хук
`useStatuses(path)` (`src/hooks/use-statuses.ts`). Вспомогательные функции —
`src/lib/statuses.ts`: `BUILTIN_STATUSES` (семь встроенных, как у сервера),
`getStatusCategory`, `isDoneStatus`. `groupBeadsByStatus(beads, statuses)`
делает группу на каждый статус списка; статус не из списка уходит в open с
предупреждающим значком. Предупреждение в строке фильтров, выбор статуса в
карточке задачи и фильтр по статусу строятся по списку проекта; в карточке
виден настоящий статус (раньше blocked показывался как Open).

**Временно, до 5fk.3.** Доска всё ещё рисует постоянные колонки, поэтому всё,
у чего нет колонки, складывается в open со значком своего статуса —
`src/lib/board-fold.ts` (`boardColumns`, `foldIntoBoardColumns`). In Review
рисуется только там, где такой статус заведён. Счётчики на главной до 5fk.5
считает `src/lib/home-counts.ts`: всё, кроме четырёх статусов с отдельным
счётчиком, идёт в open. Оба файла удаляются целиком в своих задачах.

**Что проверить, если сломается.** Доска долго показывает «Loading beads…» —
она ждёт и задачи, и список статусов; смотреть запрос `/api/statuses` во
вкладке сети. Если он упал, в консоли браузера будет предупреждение
`Could not read the project's statuses` и страница работает со встроенным
списком — тогда свой статус проекта (например inreview) окажется в open с
оранжевым значком. Новый свой статус, заведённый при открытой доске, виден
после перезагрузки страницы: список читается один раз на проект.

**Что оставлено.** Колонки, их цвета, клавиши перехода и pinned наверху open —
5fk.3. Create PR, Close Epic, проверки на `closed` и счёт «в работе» у эпика
(`use-epics.ts`, `epic-parser.ts` считают только `in_progress`, hooked туда
больше не попадает) — 5fk.4. Счётчики главной по группам — 5fk.5. Поле
`beadsByStatus` убрано из `useBeads`: его никто не читал, а без списка
статусов оно не может группировать.
