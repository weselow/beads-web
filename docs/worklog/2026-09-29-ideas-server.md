# 2026-09-29 — сервер для панели Ideas: дата отложения, закрытие с причиной, истории вне счётчиков (beads-web-e3q.1)

Сервер теперь отдаёт у каждой задачи поле `defer_until` во всех ступенях
чтения: bd CLI и `bd export` (поле так и называется, принимается и
`deferUntil`), JSONL, SQL. В SQL колонка сначала проверяется через
`information_schema` (`issues_has_column` в `server/src/dolt.rs`); в старой
схеме без неё выбирается `NULL AS defer_until`, чтение не падает.
`PATCH /api/beads/update` принимает поле `defer`: дата ставит отложение,
пустая строка снимает. Для обычных проектов это `bd update --defer=<значение>`
(флаг и значение одним аргументом), для `dolt://` — SQL, который повторяет
поведение bd 1.3.0: дата → статус `deferred`, снятие → отложенная задача снова
`open`; явный статус в том же запросе главнее. `closeBead` на странице
получил необязательную причину — `bd close <id> --reason=<текст>`. Задачи типа
`story` не входят ни в группы счётчиков главной, ни в старые колонки кэша
(`counted_statuses` и `legacy_counts` в `server/src/routes/beads.rs`).

**Как ведёт себя bd 1.3.0 (проверено на черновом проекте).** После
`bd update X --defer=2026-10-10` статус становится `deferred`, а
`defer_until` в `bd list --json`, `bd show --json` и `bd export` —
`2026-10-09T20:00:00Z`: bd считает дату полуночью по местному времени и
хранит в UTC. `--defer=` (пусто) снимает дату и возвращает статус `open`,
даже если до отложения задача была `in_progress`. `bd close X --reason=...`
пишет `close_reason`; текст, начинающийся с `-`, доходит целиком.

**Что проверить, если сломается.** Нет даты у отложенных задач — посмотреть
`source` в ответе `/api/beads` и вывод `bd list --json` у этой задачи: поле
могли переименовать. Для `dolt://` отказ 400 «Defer date must be YYYY-MM-DD or
RFC 3339» — страница прислала слова вроде `tomorrow`, которые понимает только
bd. Через SQL дата без времени — полночь UTC, а не местная, как у bd: разница в
несколько часов ожидаема.

**Что оставлено как есть.** Закрытие с причиной для проектов `dolt://` не
сделано: `closeBead` идёт через `/api/bd/command`, которому нужна папка
проекта, — так же было и раньше для закрытия эпика. Доску (скрывать истории)
и саму панель делает beads-web-e3q.2.
