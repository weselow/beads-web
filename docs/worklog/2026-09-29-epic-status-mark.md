# 2026-09-29 — карточка эпика показывает пометку статуса (beads-web-nz1)

Доска (`src/lib/board-columns.ts`) кладёт в `bead._statusBadge` пометку, когда
задача стоит не в своей колонке: «Pinned» (серая) для закреплённой наверху Open и
имя статуса (оранжевая) для статуса, которого нет в списке проекта. Обычная
карточка её рисовала, а `EpicCard` поле не читал вовсе — эпик в таком положении
выглядел как обычный открытый. Теперь `src/components/epic-card.tsx` собирает
пометку один раз (`statusMark`) и ставит её во все три раскладки: compact-row
(Linear Minimal) — после метки EPIC, property-tags (Notion Warm, GitHub Clean) —
после метки Epic, основная — в шапке перед меткой EPIC. Цвета пометки —
`getStatusBadgeClasses`, перенесённая из `bead-card.tsx` в `src/lib/statuses.ts`,
чтобы обе карточки брали её из одного места. Если пометка у эпика пропала —
сначала проверить, что `buildBoardColumns` по-прежнему кладёт `_statusBadge`, а
тест `epic-card-status-mark.test.tsx` проверяет каждую раскладку. Не тронуто:
у обычной карточки пометка прячется для заблокированной задачи со статусом
`blocked`; эпику это правило не нужно — `blocked` есть в списке встроенных
статусов, и доска такой пометки не ставит.
