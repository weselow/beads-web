# 2026-09-29 — дерево: компонент вида со строками (beads-web-0l7.2)

Компонент `TreeView` (`src/components/tree-view.tsx`) рисует дерево из
`buildTree`/`flattenVisible` (`src/lib/tree.ts`, часть 0l7.1) плоским списком
строк `TreeRow` (`src/components/tree-row.tsx`, обёрнута в `memo`); отступ —
`padding-left` по глубине, а не вложенные блоки. У строки: стрелка (только у
узлов с детьми), значок типа, номер, заголовок-кнопка (`onOpenBead`), пометка
«parent not found» у сироты, полоса готовности done/total, приоритет, статус в
цвете своей группы. Стрелка и заголовок — разные кнопки, поэтому
сворачивание не открывает карточку. Над деревом — Expand all / Collapse all и
переключатель Show closed. Свёрнутые строки и Show closed хранит хук
`useTreeState` (`src/hooks/use-tree-state.ts`) в localStorage под ключами
`beads-web:tree:<projectId>:collapsed` и `:showClosed`; ошибки хранилища
пишутся в `console.warn`, дерево работает и без него. На страницу компонент
подключает часть 0l7.3.

Заодно вынесены общие части, чтобы не копировать: цвет полосы готовности
(`src/lib/progress.ts`, раньше внутри `epic-card.tsx`), значок P0–P2
(`src/components/priority-badge.tsx`, раньше внутри `bead-card.tsx`) и
переключатель (`src/components/ui/toggle-switch.tsx`, раньше внутри
`journal-switch.tsx`).

**Что проверить первым, если сломается.** Строки перерисовываются все
разом — значит, `onOpenBead` со страницы меняется на каждой отрисовке (нужен
`useCallback`) или пересоздаются `beads`/`matchedIds`/`compare`, и дерево
собирается заново. В тестах под Node 25 глобальный `localStorage` — пустая
заглушка Node, а не хранилище jsdom: тест подставляет своё хранилище через
`vi.stubGlobal`.

**Замер** в jsdom на 1210 сгенерированных задачах (4 уровня): первая
отрисовка 0,8–1 с, Expand all ~0,7 с, свернуть одну строку 10–16 мс,
Collapse all ~75 мс, скрыть закрытые ~0,2 с. jsdom заметно медленнее
браузера; живой замер — после 0l7.3. Виртуальный список не добавлялся.

**Оставлено как есть.** Id в сохранённом списке свёрнутых, которых больше нет
в данных, не удаляются — они ничему не мешают. Клавиатурная навигация по
дереву стрелками (полный шаблон ARIA tree) не делалась: строки — обычный
список, кнопки доступны по Tab.
